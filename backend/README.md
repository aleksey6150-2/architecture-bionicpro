# backend

Здесь живут все собственные бэкенд-сервисы проекта BionicPRO.

## Сервисы

| Сервис                           | Назначение                                                           | Порт |
|----------------------------------|----------------------------------------------------------------------|------|
| [bionicpro-auth](bionicpro-auth) | BFF: OAuth-флоу с Keycloak, сессии, ротация session_id, прокси к API | 9000 |

По мере появления других сервисов (например, `reports-api`) они тоже будут лежать
здесь подпапками.

## Общие договорённости

- Java 25 LTS, Spring Boot 4.0.x
- Сборка — Maven
- Артефакт `groupId = com.bionicpro`
- Каждый сервис — самостоятельный Maven-проект (без общего parent pom-а пока)
